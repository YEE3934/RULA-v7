# RULA 最終結案候選版本（2026-10-30）

## 這次最後修正了什麼？

1. **外側工作誤判**：保留前一版肩／髖雙參考點、肘→腕方向、可見度與前臂跨中線最多 +1 的規則，*沒有*為了讓 11 張人工樣本全通過就擅自調整門檻。現在在「✅ 照片批次補正」可選取影格用「⚡ 單張快速確認」設定有／沒有；在「🧩 剔除樣本」若未知條件影響總分，也能就地選有／沒有、儲存並重新計分。兩個地方都只修改目前影片的該張、該側，不會把舊影片編號寫死到新影片。已知誤判須經人工確認，不能把純自動判定當人體姿勢真值。
2. **已點維持但正式總分仍空白**：如果外側工作不確定且有／無會改變總分，異常中心不再讓「維持自動評分」冒充已確認；會提供明確的「有／沒有」選項。未解決時維持待確認；完成後使用同一套 Table A/B/C 重新算分。
3. **CSV 很多無法判斷**：新增 `複核後結果/外側工作逐筆判定與影響.csv`，區分「未知但總分不變（免確認）」和「未知且會影響評分（需確認）」，並保留採用來源；`複核後結果/逐張人工補正確認.csv` 同步補上這些欄位。未知不被偽裝成真實「否」。
4. **肌肉使用、負重**：在第一步新增實際重量／每分鐘重複頻率文字欄，以及「已依現場條件核對」勾選。仍依既有每段時軸設定加分，不會透過照片猜物體重量或修改使用者設定；未勾選時可試跑，結果頁提醒，ZIP 中 `評估結果/作業條件確認.csv` 明列「待確認」。
5. **結案驗收清單**：結果頁新增 `✅ 結案驗收` 分頁，7 項逐項勾選與進度條。每次執行新分析會重置勾選，下載 ZIP 會附 `結案驗收/使用者勾選紀錄.csv`；另附程式自動整理的 `結案驗收/驗收清單.csv`。勾選是人工流程紀錄，**不代表程式已證明辨識百分之百正確**。

## 操作順序（一次完成，不用全部照片都人工評分）

1. 將本 ZIP 內容整包更新到原本 Streamlit GitHub 專案。Streamlit 主程式為 `222.py`，Python 建議 3.11，保留 `requirements.txt`、`packages.txt`、`timeline_component/index.html` 和 `scripts/download_hand_model.py`。
2. 用相同三支原始影片重新分析（例如 30 張），在第一步核對實際負重與肌肉使用（可以依影片階段分段）；若不清楚，先標「尚未確認」，不要直接把任意 +3 寫成已驗證。
3. 先看結果總覽的待處理數量；到 `✅ 照片批次補正` 或 `🧩 剔除樣本`，只處理**會影響分數**的未知外側工作。已知人工標記的第 1、3、6、7、8、16、17、18、20、26、27 張可以作為驗證參考，但必須確保是同一支影片、同一側手，不能直接套到其他影片。
4. 到「📐 角度檢視 → 頸部」處理必要的共同頸部分數。確定是骨架失敗的樣本可以保留明確剔除紀錄，**不需要硬補一筆假的分數**。
5. 到「✅ 結案驗收」逐項勾選；最後在「📦 下載」產生新 ZIP 再提供驗收，不要以原始系統照片上的舊分數代替複核後 CSV。

### 必須留意

- 有／無外側工作即便 RULA Grand Score 一樣，**也不表示它的影像判定是正確的**；僅代表此筆不需要為了總分再逐張確認。
