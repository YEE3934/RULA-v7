# RULA 使用者介面修正版｜2026-10-30

## 部署方法

1. 將本資料夾內容完整上傳 GitHub 專案根目錄，不要只上傳 `222.py`。
2. Streamlit Cloud 設定主程式路徑 `222.py`，Python 3.11。依 `requirements.txt` 安裝依賴。
3. 保留 `timeline_component/index.html`、`models/README.txt`、`scripts/download_hand_model.py`，以及 `packages.txt`。
4. 舊網站若仍顯示舊版步驟或舊 checkbox 狀態，請重新整理開啟新工作階段，再重新上傳影片。

## 這次介面修改

- 上傳所選評估側影片後，**影片時間軸直接展開**。主要拖曳元件與原生雙端點 slider 備援均可設定負重／肌肉使用時段。預設參考所選的側視角，無須先切左右側重載。
- 設定改為 **影片、時間同步、自動辨識、啟動分析** 四步；取消原本套用整批照片的「人工確認條件」步驟。這不代表原本需人工確認的項目變成全自動。
- 可用影像自動辨識項目預設啟用，舊工作階段可按「一鍵啟用全部可用的自動辨識項目」。**頸部側彎**沒有通過假陽性驗證，因此不開啟其自動加分；**軀幹側彎**仍使用正面 2D 代理幾何判定。
- 腿足支撐／平衡與腕扭轉若無影像證據，改採**初始正常基礎假設各 1 分**；這些條件**不是自動辨識**，須按實際工作情況在照片補正中更正。高風險現場不可無驗證直接採信。
- 結果頁的「異常／人工覆核」整合 **待確認照片、照片補正、頸部確認、角度檢視、異常／人工評分**；在待確認頁直接看編號、側別、原因與照片，並能單張修改前臂外側工作及共同頸分。
- 研究者自用的「結案驗收」已從網站、匯出 ZIP 及交付專案中移除。一般使用者不需要執行研究結案驗收。
- 原始分析與複核後報表保留分開，RULA Table A/B/C 未更動。

## 測試與限制

- `python -m py_compile 222.py`
- `python -m unittest discover -s tests -p 'test_*.py' -q`
- 最新執行：**63 項 Python 自動化測試通過**（包含品質、計分、匯出、UI 結構與待確認樣本清單）。
- 本地環境未安裝 Streamlit / MediaPipe，**尚未實際啟動網站或重新推論三視角真人影片**；使用者仍須在部署站點完成首次開頁、拖曳時間軸、照片顯示與重新匯出 ZIP 的驗收。
- 臉、頸、軀幹等 2D 投影角度不等於經校準的人體解剖角度；誤判不能因程式能計算出分數而視為已證實準確。
